🔐 Full Stack Login System (Em Desenvolvimento)

Sistema de autenticação e gerenciamento de acesso desenvolvido com PHP, MySQL, JavaScript, HTML5 e CSS3.

O projeto demonstra a integração entre Front-End, Back-End e banco de dados relacional, permitindo o cadastro de usuários, autenticação e controle de acesso baseado em níveis de permissão.

🖥️ Sobre o Projeto

O Full Stack Login System foi desenvolvido com o objetivo de colocar em prática conceitos fundamentais do desenvolvimento web, incluindo autenticação, manipulação de dados, gerenciamento de sessões e integração com MySQL.

A aplicação apresenta uma interface moderna e intuitiva, com áreas distintas para usuários e administradores.

🚀 Funcionalidades

Cadastro de novos usuários.

Autenticação por e-mail e senha.

Integração com banco de dados MySQL.

Armazenamento seguro de senhas utilizando hash.

Gerenciamento de sessões com PHP.

Controle de acesso baseado em permissões.

Dashboard exclusivo para administradores.

Área dedicada para usuários.

Logout e encerramento de sessão.

Interface responsiva.
